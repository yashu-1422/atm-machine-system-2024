
# 💳 ATM Machine System

Welcome to the **ATM Machine System** — a sleek, user-friendly desktop application built with **Python** and **Tkinter** that simulates a real-world ATM experience!  
Manage your bank account effortlessly with features like account creation, secure login, deposits, withdrawals, balance checks, and transaction history — all wrapped in a clean graphical interface.

---

## 🎯 Project Goals

- Craft an intuitive GUI to simplify banking operations  
- Ensure secure authentication and privacy for every user  
- Support all fundamental ATM functionalities: withdraw, deposit, check balance, and more  
- Maintain a detailed and accessible transaction log for transparency

---

## 🏗️ Architecture Overview

This app uses a straightforward **client-server** design pattern:  

- **Client:** The front-end GUI built with Tkinter, handling all user interactions smoothly  
- **Server:** A Python `shelve` database backend that safely stores account details and transaction data persistently  

---

## 🖥️ Application Features

| Feature               | Description                                           |
|-----------------------|-------------------------------------------------------|
| **Start Page**         | Log in or create a new user account                   |
| **Menu Dashboard**     | Quick access to all banking operations                |
| **Account Creation**   | Simple form for new users to register                 |
| **Withdraw Funds**     | Withdraw money with real-time balance validation      |
| **Deposit Funds**      | Securely add money to your account                     |
| **Balance Inquiry**    | View your current account balance instantly           |
| **Transaction History**| Browse all past transactions in detail                |
| **Account Management** | Reset passwords and delete accounts safely             |

---

## ⚙️ Technologies Used

- **Python 3** — Core programming language  
- **Tkinter** — Lightweight, native GUI toolkit  
- **Shelve** — Python’s simple key-value file-based database for persistent storage
